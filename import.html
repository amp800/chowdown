Import Recipe

Paste a recipe URL — a GitHub Actions workflow scrapes it and commits directly to the repo. Takes about 30 seconds to appear.

GitHub Token — stored in your browser only, never sent to a server

Classic token needs repo + workflow scopes (or fine-grained Contents: read/write + Actions: write) — photo import uploads the photo to the repo too. Create one here →

Import from Photo

Snap a photo of a printed cookbook or magazine page — Gemini vision (free, no cost) reads the recipe straight off the page, and your photo becomes the recipe image.

Recipes are imported via URL import or photo import GitHub Actions. You can monitor progress there. The page rebuilds automatically once the workflow commits the file.
