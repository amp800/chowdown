Import from Email Receipt

Copy and paste the text of your FreshDirect or Whole Foods order confirmation email. The importer will extract item names and add them to your on-hand list.

Runs a GitHub Actions workflow that parses the email text and commits the results to _data/pantry.yml. Reload the page after ~30 seconds to see the updated list. Requires your GitHub token to be saved on the Import page.
